# DESIGN.md - OYOTEE Clean Modern E-Commerce System

## Overview
A clean, modern, product-led e-commerce interface inspired by the OYOTEE design system. It features a spacious light background, rich forest & vibrant green accents, soft pill/rounded surfaces, clear grid layouts, and structured side panels for quick filtering and item preview.

## Colors
- **Primary Green (`#3E9B56`):** Main interactive call-to-action buttons, active navigation pills, and primary highlights.
- **Dark Forest Green (`#0B4619`):** Hero/promo section background, deep contrast elements, and brand accents.
- **Accent Yellow (`#FFC107`):** Ratings, special offer badges, and high-visibility CTAs.
- **Background Main (`#F8FAF8`):** Off-white clean page foundation with subtle warmth.
- **Card & Panel Surface (`#FFFFFF`):** Crisp white containers for product cards, sidebars, and detail drawers.
- **Subtle Border (`#E4E4E7`):** Soft borders for clean separation without visual noise.
- **Text Main (`#1F2937`):** Dark charcoal for high legibility headings and titles.
- **Text Muted (`#6B7280`):** Secondary text, category tags, and supporting copy.
- **Wishlist Heart Red (`#EF4444` / `#FEE2E2`):** Interactive bookmark/like buttons.

## Typography
- **Font Family:** Clean Sans-Serif (`Inter`, `Plus Jakarta Sans`, system-ui).
- **Headings:** Semibold to Bold (20px - 32px), tight tracking for clean modern look.
- **Body & Controls:** 13px - 16px, readable line height (1.5).

## Layout & Components
- **Top Navigation Bar:** Sticky top bar with logo, category tabs, search trigger, cart counter, and action icons.
- **Sidebar Filters:** Categories, price range controls, rating filters, and promotional banners.
- **Product Cards:** Rounded containers (`16px`), high-resolution thumbnail, category tag, star rating, price, and primary "Add to Cart" / WA order buttons.
- **Product Detail Side Drawer:** Instant side preview drawer with image gallery, detailed specifications, and quick checkout CTAs.
- **Buttons & Pills:** Heavy rounded corners (`rounded-2xl` / `rounded-full`), clear visual hierarchy between primary solid buttons and subtle outline secondary actions.
